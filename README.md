## 💻 How to View & Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` or drag and drop it into any modern web browser (Google Chrome, Microsoft Edge, Brave, Mozilla Firefox, Safari).

### Option 2: Live Server (VS Code / Extension)
Right click `index.html` and click **"Open with Live Server"**.

### Option 3: PowerShell / Command Line
If Python or Node is available in your environment:
```powershell
# Python
python -m http.server 8080

# Or Node (npx)
npx serve .
```
Then visit `http://localhost:8080` in your browser.

## 🌐 Instant Free Deployment

This static website requires zero build steps or server runtimes. It can be hosted on:

1. **GitHub Pages**: Push this directory to a repository and enable GitHub Pages in Settings -> Pages.
2. **Vercel**: Run `npx vercel` or import the GitHub repository on [vercel.com](https://vercel.com).
3. **Netlify**: Drag-and-drop the `sainex-cyber-shield` folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
4. **Cloudflare Pages**: Connect your Git repo for automatic deployment on Cloudflare's global edge network.
